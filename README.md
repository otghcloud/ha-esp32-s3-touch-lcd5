# Waveshare Touch LCD HA-Panel

A Home Assistant touch dashboard for the **Waveshare ESP32-S3-Touch-LCD-5**, powered by ESPHome.

## What it does

- Up to eight configurable pages, with 4, 8 or 18 controls per page.
- Toggle lights, switches and automations; operate locks.
- Drag-and-drop page ordering, custom titles and Material Design icons.
- Light details with brightness, colour temperature, a colour wheel and two related controls.
- Clock screensaver, presence-sensor wake, local Sleep/Restart and optional Homepage.

Pages and entities are configured through a Home Assistant blueprint, without rebuilding firmware.

## Requirements

- Waveshare ESP32-S3-Touch-LCD-5 with 16 MB flash.
- Home Assistant **2025.7 or newer**.
- ESPHome Device Builder, or a standalone ESPHome installation.
- Internet access when building, to download dependencies and fonts.

## 1. Install the firmware

Create a device in ESPHome Device Builder. Add these entries to its private `secrets.yaml`:

```yaml
panel_wifi_ssid: "your-wifi-name"
panel_wifi_password: "your-wifi-password"
panel_api_key: "your-generated-api-encryption-key"
```

Generate an API key with `openssl rand -base64 32`, or reuse the key generated by ESPHome.

Replace the device configuration with this example, adjusting the device names:

```yaml
substitutions:
  device_name: "office-panel"
  friendly_name: "Office Panel"
  wifi_ssid: !secret panel_wifi_ssid
  wifi_password: !secret panel_wifi_password

api:
  encryption:
    key: !secret panel_api_key

packages:
  wallpanel:
    url: https://github.com/otghcloud/ha-esp32-s3-touch-lcd5
    ref: main
    refresh: 300s
    files:
      - ha-esp32-s3-touch-lcd5.yaml
```

Validate, build and install using ESPHome Device Builder. Use a USB/factory installation for the first flash. Later updates can use OTA.

> These URLs use the published `main` branch. Unpublished changes are not available through them. Keep your secrets private.

## 2. Connect Home Assistant

1. Add the panel through Home Assistant's **ESPHome integration**.
2. In the integration's device configuration, enable **Allow the device to perform Home Assistant actions**.
3. Keep the **Dashboard endpoint** diagnostic entity enabled.

The screen initially says **Waiting for Home Assistant**. Configure the blueprint next.

## 3. Configure the dashboard

Under **Settings > Automations & scenes > Blueprints > Import blueprint**, import:

```text
https://raw.githubusercontent.com/otghcloud/ha-esp32-s3-touch-lcd5/refs/heads/main/wallpanel_blueprint.yaml
```

Create an automation from **Waveshare Touch LCD HA-Panel**:

1. Select the panel device.
2. Fill in the button pages you want. Choose **2x2**, **4x2** or **6x3** for 4, 8 or 18 controls.
3. Choose entities, optional title overrides, page icons and temperature sensors. Empty pages are hidden.
4. Under **Navigation > Page order and titles**, set page titles and drag rows into order. Keep each row's page slot unchanged.
5. Save and enable the automation, then run its actions once.

Keep **one dashboard automation per panel** enabled. Future state changes and reconnects update it automatically.

## Using the panel

- **Tap** a control to operate it. Automations enable/disable rather than run their actions. Locks operate immediately, without confirmation.
- **Swipe left/right** to move between pages.
- Tap the **menu** icon for Navigation or the **cog** for Settings.
- **Hold a light icon for 600 ms** to open details, headed with its parent page and item title, such as **Office - Lamp**.
- In details, use **State** to toggle the light and choose an available adjustment mode. Drag to preview; release to send one command. The footer arrow returns to the parent page.
- Missing light readings are hidden while off, or replaced with a “Choose…” prompt while on. Colour is shown as an RGB hex code. Connection and command errors remain visible.
- In **Light details > Related controls**, optionally add up to two lights, switches or automations beside a primary light.

Active controls are normally white. **Appearance > Reverse active state** changes that visual rule, not the action. Locks are normally active when unlocked.

## Display settings

The panel device's Home Assistant **Configuration** section provides:

| Setting | Purpose |
| --- | --- |
| Display timeout | Seconds before backlight-off; `0` disables it. |
| Screensaver time | Seconds before the clock view; `0` disables it. Also enable Screensaver in the blueprint. |
| Wake-up page | Last-used page, a specific page, Homepage or Navigation. |
| Display backlight | Manual on/off control. |
| Restart | Reboot the panel. |

The first touch after sleep/screensaver **only wakes** the panel. Release, then touch again to operate it.

Choose date/time formats and optional binary wake sensors in the blueprint. Wake sensors can hold the display awake; manual Sleep takes priority until a fresh activation or touch. Backlight dimming is not supported.

## Updating and troubleshooting

- Install updated firmware first, then re-import the blueprint and reload automations when its inputs change.
- OTA updates blank the backlight until reboot. If an upload fails or aborts, its previous state is restored.
- **Waiting for Home Assistant:** check the integration, enabled Dashboard endpoint and dashboard automation, then run the automation once.
- **Controls missing:** check the page layout's capacity and Navigation layout.
- **Changes not appearing:** allow the package cache to refresh, then clean/rebuild firmware if necessary.
- **Frequent Activity entries:** dashboard automation runs are normal. See the [Activity filter instructions](./DEVELOPER.md#activity-and-diagnostic-logging) to hide just that automation.

For detailed settings, diagnostics, local builds, tests and protocol information, see [DEVELOPER.md](./DEVELOPER.md).
